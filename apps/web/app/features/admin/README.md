# admin/

Staff loader errors, account admin authorization and consistent decision labels. The API independently enforces all role/MFA/resource permissions.

Account pages use native forms, bounded server search and escaped audit text. See [staff operations](../../../../../docs/architecture/admin-operations.md).

The staff catalog searches all course states and links to curriculum/history inspection. Publication archival requires a shareable reason and preserves enrolled access; both search and decisions work without JavaScript.
