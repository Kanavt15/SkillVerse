# Roadmap

SkillVerse is built in phases. Every phase ends **deployable**, with tests passing and docs updated. Each phase gets its own `phase-N.md` with scope and a done-checklist when it starts.

Updated **2026-10-11**. Use [TODO.md](../../TODO.md) for completed functionality, ordered Phase 1 acceptance tasks and later-phase checklists; [plan.txt](../../plan.txt) records the current architecture and delivery agreements. Implementation and production/provider verification are tracked separately. Finish Phase 1 acceptance before paid commerce.

| Phase | Name                                 | Highlights                                                                                                                                                                                                                                          | Status         |
| ----- | ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| 0     | [Foundation](phase-0.md)             | Monorepo, API and web skeletons on Workers, D1 schema, security baseline, design system, docs, CI; deferred archive/deployment checks remain open                                                                                                   | Implemented    |
| 1     | [Core learning platform](phase-1.md) | Auth, profiles, onboarding, catalog/search, Studio/review queue, learner player, reviews, Q&A, notifications, completion certificates, admin basics and legal pages                                                                                 | ⏳ In progress |
| 2     | Monetization (launch-ready)          | Cart, coupons, Razorpay checkout, double-entry ledger, wallet, GST invoices, refunds, instructor payouts (Route), AdSense + consent + house ads, referrals, email, SEO, **Demand Radar**, bundles and pay-what-you-want                             | Planned        |
| 3     | Engagement                           | XP, streaks, achievements, leaderboards, practice arena (browser + Judge0), contests, learning paths, offline PWA, **Skill Map**, **Study Pods**, **Leagues**, **Skill Duels**, **Teach-back**                                                      | Planned        |
| 4     | Paid certifications                  | Question banks, timed exams, integrity logging, verifiable credentials, LinkedIn add-to-profile, **Skill Passport**, **capstone projects + peer review**                                                                                            | Planned        |
| 5     | Mentoring and skill swap             | Mentor profiles, availability, booking + escrow, skill-swap with **Swap Chains**, time credits, chat, **Skill Bounties**, **Office Hours**                                                                                                          | Planned        |
| 6     | Subscriptions and growth             | SkillVerse Plus, instructor revenue pool, sponsored listings, affiliates, AI tutor/quiz/captions/search, **Seasons**, **Guilds**, **Skill Snacks**, flashcards, study planner, course co-pilot, Hindi captions, scholarships, **Commitment Pledge** | Planned        |
| 7     | B2B, careers, global                 | Teams plan, cohorts and workshops, job board + recruiter search, Stripe + multi-currency + regional pricing, Hindi UI                                                                                                                               | Planned        |

**Next:** privileged staff controls, public policies/account privacy, remaining browser/manual accessibility coverage, metadata/performance and deployment/recovery gates. See [Phase 1](phase-1.md) and the [ordered master checklist](../../TODO.md#remaining-phase-1-tasks---execute-in-this-order).

R2 uploads are a Phase 2 media extension; code execution waits for Phase 3. Current completion certificates are separate from Phase 4 exam credentials, and current video checkpoints are reflections rather than graded quizzes. Feature flags and pricing fields do not mean commerce or subscriptions are implemented.

**Before charging real money** (end of Phase 2): complete reviewed commercial/compliance requirements, activate the payment provider and verify settlement/refund/reconciliation workflows. See [compliance planning](../business/compliance.md). AdSense approval/consent is a separate gate for enabling ads; commerce can launch with ads disabled.
