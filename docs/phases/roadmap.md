# Roadmap

SkillVerse is built in phases. Every phase ends **deployable**, with tests passing and docs updated. Each phase gets its own `phase-N.md` with scope and a done-checklist when it starts.

| Phase | Name                        | Highlights                                                                                                                                                                                                                                          | Status      |
| ----- | --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| 0     | [Foundation](phase-0.md)    | Monorepo, API and web skeletons on Workers, D1 schema, security baseline, design system, docs, CI                                                                                                                                                   | ✅ Complete |
| 1     | Core learning platform      | Auth (password, Google, email link, 2FA), profiles, onboarding, catalog + search, course builder, review queue, player with **interactive video**, reviews, Q&A, notifications, certificates, admin basics, legal pages                             | ⏳ Next     |
| 2     | Monetization (launch-ready) | Cart, coupons, Razorpay checkout, double-entry ledger, wallet, GST invoices, refunds, instructor payouts (Route), AdSense + consent + house ads, referrals, email, SEO, **Demand Radar**, bundles and pay-what-you-want                             | Planned     |
| 3     | Engagement                  | XP, streaks, achievements, leaderboards, practice arena (browser + Judge0), contests, learning paths, offline PWA, **Skill Map**, **Study Pods**, **Leagues**, **Skill Duels**, **Teach-back**                                                      | Planned     |
| 4     | Paid certifications         | Question banks, timed exams, integrity logging, verifiable credentials, LinkedIn add-to-profile, **Skill Passport**, **capstone projects + peer review**                                                                                            | Planned     |
| 5     | Mentoring and skill swap    | Mentor profiles, availability, booking + escrow, skill-swap with **Swap Chains**, time credits, chat, **Skill Bounties**, **Office Hours**                                                                                                          | Planned     |
| 6     | Subscriptions and growth    | SkillVerse Plus, instructor revenue pool, sponsored listings, affiliates, AI tutor/quiz/captions/search, **Seasons**, **Guilds**, **Skill Snacks**, flashcards, study planner, course co-pilot, Hindi captions, scholarships, **Commitment Pledge** | Planned     |
| 7     | B2B, careers, global        | Teams plan, cohorts and workshops, job board + recruiter search, Stripe + multi-currency + regional pricing, Hindi UI                                                                                                                               | Planned     |

**Before charging real money** (end of Phase 2): complete the [compliance checklist](../business/compliance.md), and get Razorpay activation and AdSense approval on your own domain.
